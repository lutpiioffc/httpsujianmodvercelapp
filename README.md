# UJIAN AI MOD PRO - Smart Exam, Smart Future

Aplikasi Ujian Online berbasis web modern, responsif untuk perangkat Android maupun PC, dengan fitur kecerdasan buatan (*AI MOD*) terintegrasi, desain futuristik, dan panel admin lengkap.

## Struktur Folder Proyek
```text
ujian-ai-mod-pro/
├── index.html        # Struktur utama aplikasi dan antarmuka layar
├── style.css         # Desain premium, dark mode, warna neon ungu & biru
├── script.js         # Seluruh logika ujian, timer, AI assistant, & localStorage
├── assets/           # Folder aset gambar atau ikon pendukung
└── README.md         # Panduan instalasi dan menjalankan aplikasi
```

## Fitur Utama
1. **Login Siswa & Dashboard Modern:** Masukkan nama, kelas, dan nomor peserta untuk mengakses ujian serta riwayat pengerjaan.
2. **Sistem Ujian Lengkap:** Pilihan ganda, benar/salah, esai, timer otomatis, navigasi soal, dan perhitungan nilai instan.
3. **AI MOD & Study Assistant:** Analisis hasil ujian secara mendalam, penjelasan soal sulit, petunjuk pengerjaan (*hint*), dan generator materi.
4. **Panel Administrator:** Kelola ujian, tambah/edit/hapus soal, lihat rekap nilai seluruh siswa, dan ekspor hasil ke CSV.
5. **Leaderboard & Sertifikat:** Sistem peringkat nilai siswa dan unduhan sertifikat hasil kelulusan.

## Cara Menjalankan
1. Ekstrak file ZIP ini.
2. Buka file `index.html` menggunakan browser Google Chrome (di PC maupun HP Android).
3. Aplikasi siap digunakan secara instan!
